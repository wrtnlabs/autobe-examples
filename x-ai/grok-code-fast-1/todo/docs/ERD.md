### `todo_app_todos`

User's personal todo items represent the core functionality of the todo
application.

Each todo item contains a task that an authenticated user wants to track
and complete. Todos are strictly owned by individual users with full CRUD
permissions for their own items. The system maintains separate todo
collections for each user, ensuring complete data privacy.

Todo items support basic task tracking with optional descriptions,
completion status tracking, and timestamp audit trails. Users can create
unlimited personal tasks and manage them independently without
interfering with other users' todo lists.

The main business purpose is to help users organize their daily
responsibilities through a simple, reliable task management system.

Properties as follows:

- `id`: Primary Key.
- `todo_app_user_id`: Owner user's [todo_app_users.id](#todo_app_users).
- `title`: Todo item title (required field). Must be 1-200 characters.
- `description`: Optional description of the todo item. Can be up to 1000 characters.
- `complete`
  > Completion status of the todo item. True when completed, false when
  > pending.
- `created_at`: Timestamp when the todo item was first created.
- `updated_at`: Timestamp when the todo item was last modified.
