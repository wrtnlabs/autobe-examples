# User Stories

This document provides user stories to illustrate how different types of users will interact with the discussion board. These stories are meant to guide development by clarifying the intentions and goals behind user actions.

## As a Guest...

A guest is an unauthenticated visitor whose primary goal is to explore the content available on the platform.

- **As a guest,** I want to view a list of the most recent articles on the homepage, so that I can quickly see what topics are currently being discussed.
- **As a guest,** I want to read any article and view its attached images and files, so that I can fully understand the content without needing to sign up.
- **As a guest,** I want to read comments on an article, so that I can see the community's perspective on the topic.
- **As a guest,** I want to be prompted to register or log in when I attempt to write a comment or post an article, so that I understand how to become a contributor.

## As a Member...

A member is an authenticated user who is the primary content creator and interactor on the platform.

### Content Creation and Management
- **As a member,** I want to create a new article with a title and a rich text body, so that I can share my thoughts and opinions on economic and political topics.
- **As a member,** I want to attach images and other files (like PDFs or documents) to my articles, so that I can provide supporting evidence, sources, or visual context.
- **As a member,** I want to edit my own articles after posting, so that I can correct typos, update information, or improve my content.
- **As a member,** I want to delete my own articles, so that I have full control over the content I have published.

### Community Interaction
- **As a member,** I want to post comments on articles, so that I can participate in discussions and share my viewpoint.
- **As a member,** I want to edit or delete my own comments, so that I can correct mistakes or remove a comment I no longer stand by.

### Account Management
- **As a member,** I want to be able to log out securely, so that my account is not accessible to others on a shared device.
- **As a member,** I want to change my password, so that I can maintain the security of my account.

## As an Admin...

An admin is a privileged user responsible for maintaining the health and safety of the community through content moderation and user management.

### Content Moderation
- **As an admin,** I want to view any article or comment on the platform, so that I can oversee all user-generated content.
- **As an admin,** I want to delete any article that violates the community guidelines, so that I can maintain a safe and constructive environment.
- **As an admin,** I want to delete any comment that is offensive, spam, or off-topic, so that discussions remain productive and respectful.

### User Management
- **As an admin,** I want to view a list of all registered members, so that I can monitor the user base.
- **As an admin,** I want to be able to ban a member's account, so that I can prevent repeat offenders from disrupting the community.
- **As an admin,** I want to unban a member, so that I can reinstate users who were banned by mistake or have served their penalty.
