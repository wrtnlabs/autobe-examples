### `todo_list_password_reset_tokens`

Password reset tokens for secure account recovery.

Stores temporary, time-limited tokens sent via email when users request
password resets. Each token is cryptographically secure, single-use, and
expires after 1 hour to maintain security.

Tokens are created when users initiate password reset through the "Forgot
Password" flow. The system generates a unique token, stores it with the
user's email, and sends a reset link containing the token. When users
click the reset link, the system validates the token hasn't expired or
been used, then allows password update.

After successful password reset or token expiration, tokens are
permanently deleted from the system. This table supports the self-service
password recovery mechanism while maintaining strict security controls.

Multiple tokens can exist for the same user if they request password
reset multiple times before using a token, though only unexpired tokens
are valid for password reset operations.

Properties as follows:

- `id`: Primary Key.
- `todo_list_user_id`: User who requested the password reset. [todo_list_users.id](#todo_list_users)
- `token`
  > Cryptographically secure random token sent in password reset email. Must
  > be unique across all active tokens to prevent collisions. Used to verify
  > password reset requests.
- `email`
  > Email address where the password reset link was sent. Stored for
  > validation to ensure the token is used with the correct email, providing
  > additional security layer.
- `created_at`
  > Timestamp when the password reset token was generated. Used to calculate
  > token expiration (tokens expire 1 hour after creation).
- `expires_at`
  > Timestamp when this token becomes invalid. Set to 1 hour after creation.
  > System rejects password reset attempts using expired tokens.
- `used_at`
  > Timestamp when the token was successfully used to reset password. Null
  > for unused tokens. Once set, the token cannot be reused, enforcing
  > single-use security requirement.
