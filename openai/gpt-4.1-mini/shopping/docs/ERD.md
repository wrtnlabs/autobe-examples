- `seller_id`: Belonged seller's [shopping_mall_sellers.id](#shopping_mall_sellers).
- `suspension_reason`: Reason for suspending the seller account.
- `suspended_at`: Datetime when the seller was suspended.
- `created_at`: Record creation timestamp.
- `updated_at`: Record last update timestamp.
- `deleted_at`: Record soft deletion timestamp; null if active.
