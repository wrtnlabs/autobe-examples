### `discussion_board_guests`

Temporary guest accounts identified by device and anonymous attributes.

This table stores records representing unauthenticated guest users
temporarily connected to the discussion board. Each guest is uniquely
identified by device fingerprint and anonymous session attributes to
enable limited tracking and user experience customization without full
registration.

No authentication credentials are stored as guests do not log in.
Temporal fields track creation, update, and soft deletion statuses.

Separate session table discussion_board_guest_sessions tracks login
sessions separately.

Properties as follows:

- `id`: Primary Key.
- `device_fingerprint`
  > A unique string fingerprint identifying the guest's device for session
  > continuity and tracking.
- `user_agent`
  > User-Agent string of the guest's browser or client for analytics and
  > display customization.
- `ip_address`: IP address of the guest for security and limited geo-location features.
- `anonymous_id`
  > Randomly generated anonymous identifier to uniquely represent the guest
  > user without PII.
- `created_at`: Record creation timestamp.
- `updated_at`: Record last update timestamp.
- `deleted_at`: Soft delete timestamp; null if not deleted.

Audit trail storing historical snapshots of user comments for audit,
versioning, and recovery purposes. Each snapshot retains the full state
of comment content, author information, and timestamps at a specific
point in time, ensuring traceability of changes. The table references the
original comment in discussion_board_comments and supports historical
browsing and rollback functionalities.

Properties as follows:

- `id`: Primary Key.
- `discussion_board_comment_id`: Original comment's discussion_board_comments.id.
- `body`: Comment content snapshot at the time of recording.
- `created_at`: Snapshot creation timestamp.
- `updated_at`: Snapshot last update timestamp.
- `deleted_at`: Soft deletion timestamp, if the snapshot is logically deleted.
