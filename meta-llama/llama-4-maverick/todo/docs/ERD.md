description, completion status, and timestamps for creation and last
update.

- `id`: Primary key for task identification.
- `user_id`: Foreign key referencing the user who created the task.
- `title`: Title of the task.
- `description`: Detailed description of the task.
- `completed`: Status indicating whether the task is completed.
- `created_at`: Timestamp when the task was created.
- `updated_at`: Timestamp when the task was last updated.
