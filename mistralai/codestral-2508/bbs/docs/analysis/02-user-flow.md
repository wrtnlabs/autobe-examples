# Economic Discussion Board User Flow Documentation

## User Registration

### User Registration Process

1. User navigates to the registration page.
2. User enters their email address, username, and password.
3. User clicks the "Register" button.
4. System validates the entered information.
5. System creates a new user account.
6. System sends a confirmation email to the user.
7. User clicks the confirmation link in the email.
8. System activates the user account.

## User Login

### User Login Process

1. User navigates to the login page.
2. User enters their username and password.
3. User clicks the "Login" button.
4. System validates the entered credentials.
5. System grants access to the user account.

## Creating a Post

### Post Creation Process

1. User logs in to their account.
2. User navigates to the "Create Post" page.
3. User enters the post title and content.
4. User can optionally upload attachments (images, files).
5. User clicks the "Publish" button.
6. System validates the post content.
7. System publishes the post to the discussion board.

## Editing a Post

### Post Editing Process

1. User logs in to their account.
2. User navigates to their profile page.
3. User selects the post they want to edit.
4. User clicks the "Edit" button.
5. User modifies the post title and/or content.
6. User can optionally update or remove attachments.
7. User clicks the "Save Changes" button.
8. System validates the updated post content.
9. System updates the post on the discussion board.

## Deleting a Post

### Post Deletion Process

1. User logs in to their account.
2. User navigates to their profile page.
3. User selects the post they want to delete.
4. User clicks the "Delete" button.
5. System prompts the user to confirm the deletion.
6. User confirms the deletion.
7. System removes the post from the discussion board.

## Uploading Attachments

### Attachment Upload Process

1. User logs in to their account.
2. User navigates to the "Create Post" or "Edit Post" page.
3. User clicks the "Upload Attachments" button.
4. User selects the files they want to upload (images, documents).
5. System validates the file types and sizes.
6. System uploads the files to the server.
7. User can preview the uploaded files before publishing the post.

## Viewing Posts

### Post Viewing Process

1. User navigates to the discussion board.
2. User browses the list of posts.
3. User selects a post to view.
4. System displays the post title, content, and any attachments.
5. User can scroll through the post content.

## Commenting on Posts

### Commenting Process

1. User logs in to their account.
2. User navigates to the post they want to comment on.
3. User enters their comment in the comment box.
4. User clicks the "Submit" button.
5. System validates the comment content.
6. System adds the comment to the post.
7. System notifies the post author about the new comment.
