# Service Overview: Economic/Political Discussion Board
───
## 1. Service Description
This is a straightforward discussion board enabling economic and political discourse. 

## 2. Features Provided
- Ability for people to post topics/articles with title+body
- Support for attaching images and other files to posts  
- Ability to reply/comment on topics
- Registration to allow posting (guests may browse)
- Basic moderation of content

## 3. File Attachment
Common web image formats (JPG, PNG, GIF, etc) plus documents (PDF, etc).  

Simple, intuitive, quick to deploy. Nothing fancy.
